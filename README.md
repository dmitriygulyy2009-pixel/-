# Кубок-Босс 🏆
1. Создай репозиторий на GitHub и залей ВСЁ содержимое этой папки (включая скрытую папку .github).
2. Открой вкладку Actions -> "Build APK" (запустится сам после push, либо Run workflow).
3. Когда сборка позеленеет, открой её и скачай Artifacts -> CupBoss-apk (zip с app-debug.apk).
4. Скинь APK на телефон и установи (разреши установку из неизвестных источников).
